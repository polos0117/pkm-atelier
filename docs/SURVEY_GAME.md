# 탐사 작전

`survey.html`은 대원 배치와 에너지 관리로 메달을 모으는 독립 게임이다.
전투 시험장(`battle.html`)이나 일곱 판 런(`run.html`)의 전투·드래프트·성장 규칙을 쓰지 않는다.
공유하는 것은 도감 자료, 이미지 계층, 테마, 상단 메뉴뿐이다.

## 한 판

1. 대원 여섯으로 6일간 작전한다. 목표는 탐사 메달 30개다.
2. 매일 조사·회수·구조 임무가 하나씩 나온다. 한 구역에 두 명까지 배치할 수 있다.
3. 대원과 폼을 고르면 예상 탐사력과 메달이 즉시 보인다. 출발 결과는 그 예상과 같다.
4. 출발한 대원은 에너지를 쓰고, 배치하지 않은 대원은 3 회복한다. 최대 에너지는 6이다.
5. 정비 키트 하나는 대원 하나의 에너지를 3 회복한다. 시작 키트는 3개, 보유 한도는 9개다.
6. 복귀 후 키트 2개 또는 전 대원의 한 적성 +1을 고른다. 강화는 이번 작전 동안 유지된다.
7. 6일차 복귀로 끝난다. 메달 42개부터 S, 30개부터 A, 20개부터 B, 나머지는 C다.

오늘의 작전은 브라우저의 현지 날짜 `YYYYMMDD`를 시드로 쓴다. 같은 데이터·시드에서
대원과 구역은 같다. 무작위 작전과 같은 작전 재도전도 가능하다.

## 도감 자료가 쓰이는 곳

`data/card.json`의 1,025종에서 서로 다른 조사·회수·구조 강점의 대원을 두 명씩 뽑는다.
종족값 총합이 큰 포켓몬만 우월해지지 않도록 분포를 정규화한다.

| 적성 | 정규화 전 가중값 |
|---|---|
| 조사 | 특공 × 0.65 + 특방 × 0.35 |
| 회수 | 공격 × 0.5 + 방어 × 0.3 + HP × 0.2 |
| 구조 | 스피드 × 0.75 + HP × 0.25 |

각 적성은 `2 + 24 × (해당 가중값 / 세 가중값 합계)`를 소수 첫째 자리까지 반올림한다.
장비 강화는 이 값에 더한 후 폼 배율을 적용한다.

| 폼 | 소모 | 조사 배율 | 회수 배율 | 구조 배율 |
|---|---:|---:|---:|---:|
| 경장 | 2 | 1.08 | 0.92 | 0.92 |
| 중장 | 3 | 0.9 | 1.3 | 0.7 |
| 고기동 | 3 | 0.85 | 0.85 | 1.3 |

구역 타입과 대원의 두 타입 중 하나가 맞으면 탐사력 +3. 두 대원이 알그룹을 공유하면
협업 +2를 한 번 더한다. `no-eggs`와 `ditto`는 협업에서 제외한다. 18개 타입 모두
적성이 되는 구역이 있다. 폭주 폼은 이 비전투 게임의 선택지에 넣지 않는다.

구역 필요치는 시드·날짜로 정한다. 필요치의 60% / 100% / 130% 이상이면 메달 1 / 2 / 3개,
그 미만은 0개다. 빈 구역은 0개다. 숨은 주사위나 전투 결과는 없다.
등록된 이미지는 `lib/img.js`로 읽고, 그림이 없으면 타입색과 도감번호로 표시한다.

## 코드와 저장

- `lib/survey.js`: 시드, 선발, 적성, 배치 가능 여부, 예상 결과, 진행, 저장 검증.
- `lib/survey-ui.js`: 엔진의 선택 가능 여부·결과를 소비하는 Preact 화면.
- `lib/survey.css`: 공통 테마 색을 쓰는 게임 전용 레이아웃.
- `lib/words.js`: 모든 화면 문구. 원본 도감·그룹 데이터는 변경하지 않는다.
- `pkm_survey_v1`: 진행 중 작전. `pkm_survey_best_v1`: 이 브라우저의 최고 기록.

다른 게임의 저장값은 건드리지 않는다. 잘못된 저장은 안내 후 새 작전을 시작하게 하며,
저장이 차단되어도 현재 창에서 플레이할 수 있다. 배치·폼·정비·출발·보상마다 저장한다.
화면은 공통 `.wrap` 한 곳에서 스크롤한다. 작은 화면의 구역 카드는 옆으로 넘긴다.

## 검사

```bash
node tests/survey-sim.cjs
ESM_DIR=<node_modules> CHROMIUM_PATH=<chrome> node tests/survey-screen.cjs
ESM_DIR=<node_modules> CHROMIUM_PATH=<chrome> node tests/header-layout.cjs
ESM_DIR=<node_modules> CHROMIUM_PATH=<chrome> node tests/theme-screen.cjs
```

규칙 검사는 배치 이동·정원·에너지·폼 비용·보상 중복·예상 결과·저장 복구·6일 종료를 본다.
화면 검사는 실제 선택/버튼으로 한 판을 끝내고, 도중 새로고침·재도전·저장 차단·자료 실패를 본다.
시작 에너지를 잘못 바꾸는 임시 변이로 규칙 검사가 실제로 실패하는 것도 확인했다.

시드 `20260917`부터 12개를 오늘의 예상 결과만 보는 배치기로 완주한 기록:
`40, 41, 43, 41, 40, 40, 45, 43, 44, 42, 41, 43` 메달.
이는 목표 도달 가능성을 확인하는 표본이다. 사람의 난이도나 모든 시드의 공정성을 보장하지 않는다.
배치기는 검사용이고 게임 화면에는 자동 배치 기능을 넣지 않았다.
