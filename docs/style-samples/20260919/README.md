# 화풍 선택 예시 — 피카츄

14개 화풍별 신규 기준 시트 한 장. 생성기 화면에서 피카츄, 폼 초상,
새 인물 만들기, 경장, apparent age = youthful adult를 선택하고
나머지 외형·표정은 자동, 추가 지시는 비운 상태로 출력했다.
`manifest.json`에 원본 코드 커밋과 실제 UI 설정, 파일명·크기·해시를 기록했다.

각 `<style>.txt`는 실제 `#prompt-output`에서 추출한 원문이며,
이미지 참조 없이 image_gen에 개별 제출했다. 사진풍은 출력 안전 검사에서
두 차례 차단되어 비성적 장비 설정화와 불투명한 보호 의복을 명확히 하는
안내를 덧붙였다. 해당 실제 제출문은 `photoreal-submitted.txt`다.
생성기의 화풍 문구와 선택값은 변경하지 않았다.

이미지는 `pkm-atelier-img/img/style-pikachu-youthful-20260919-<style>.webp`다.
원본 픽셀 크기와 비율을 유지해 WebP로 변환했으며 크롭이나 여백 변경은 없다.
`style-` 접두사로 도감 카드 등록에서 제외된다. 예시 컴포넌트는 화풍 키로
직접 연결하므로 현재 포켓몬·폼·모드와 관계없이 같은 화풍 예시를 보여 준다.
이미지를 누르면 원본을 새 탭으로 연다. 예시는 인물 정체성 입력으로 주입하지 않는다.

화풍별로 새 인물을 생성했으므로 자동 결정된 외형과 장비가 다르다.
시트는 화풍 선택 참고용이며 도감의 승인된 인물 기준을 대체하지 않는다.
