# 포켓몬 메카 프롬프트 생성 규칙

첨부 수정안과 후속 검토를 반영했다. 이전의 문구만 치환하는 범위에서,
사용자 요청에 따라 생성 엔진·화면·검사까지 함께 정리했다.

## 생성 흐름

1. **새 인물 만들기**: 원본 포켓몬과 화풍, 성인 여성의 외형을 선택한다.
   **이미지 첨부는 필요 없다.** 기존 인물 이미지와 포켓몬 원작 이미지 모두 필수가 아니다.
   폼 초상에서는 정면·후면 전신과 확대컷을 모은 **기준 시트 한 장**을 만든다.
2. 마음에 드는 결과를 사용자가 **기준 이미지로 확정**한다. 첫 결과가 자동 기준은 아니다.
3. **확정한 이미지 이어가기**: 이미지 생성 서비스에 그 이미지를 첨부하고 프롬프트를 사용한다.
   생성기는 이미지를 전송하거나 실제로 생성하지 않는다.
4. 후속 결과를 계속 새 기준으로 교체하지 않는다. 승인한 원본을 인물 기준으로 유지한다.

이미지 이어가기는 확정한 기준 이미지 한 장으로 시작할 수 있다. 얼굴·머리·체형은 이미지가 결정한다.
저장된 외형 파라미터를 후속 프롬프트에 다시 실어 덮어쓰지 않는다.
표정과 머리의 움직임은 바꿀 수 있지만 얼굴 구조나 머리 길이는 바뀌지 않는다.

## 서로 다른 세 출력

| 열쇠 | 출력 | 적용 범위 |
|---|---|---|
| portrait + create | 최초 기준 시트 | 폼 적용. 가로폭을 넓힌 3:4 한 장에 정면·후면 전신 + 확대컷 4개 |
| portrait + reference | 폼 초상 | 폼 적용. 전신 한 컷, 2:3 비교 구도와 피사체 크기 유지 |
| action | 액션 | 폼 적용. 움직임·시점·배경 자유, 선택 화풍 유지 |
| casual | 일상컷 | 기준 인물의 새로운 장면. 폼·폼 오버라이드 미적용 |

최초 기준 시트는 왼쪽 정면 전신, 가운데 후면 3/4 전신, 오른쪽 좁은 확대컷 열로
구성한다. 확대컷은 위부터 얼굴·원본 특징을 옮긴 무늬나 장갑·등 장비와 부착부·
발과 하퇴 장갑이다. 없는 무늬나 장비를 만들지 않고 이미 있는 특징적인 구조로
대체한다. 두 전신과 확대컷은 같은 인물·같은 장갑 상태이며 좌우 배치도 같아야 한다.
인물을 작게 만들거나 빈 여백을 늘리지 않고, 문자·로고 없이 선택한 화풍을 적용한다.
3:4에서 늘어난 가로폭은 두 전신과 확대컷에 사용하며 빈 여백으로 남기지 않는다.

기준 시트로 이미지 이어가기를 하면 정면을 구도 기준으로, 후면과 확대컷은 인물·
장비의 세부 참고로 사용한다. 폼 초상에는 전신 한 명만 그리며 시트 배치를 복제하지
않는다. 비교용 단일 초상을 확정한 뒤에는 그 초상의 카메라와 피사체 크기를 유지한다.
액션·일상컷에는 최초 기준 시트 구성을 적용하지 않는다.

초상은 액션 카메라 설정을 이어받지 않는다. 액션 이미지가 인물 기준이라면
중립적인 비교 구도를 새로 정한다. 액션과 일상 설정은 화면에서도 각각 보관한다.
일상 의상은 자동으로 코스프레가 되지 않으며, 원본 색이나 작은 장신구만 남겨도 된다.
장갑은 일상 장면에서 명시적으로 요청한 경우에만 사용한다.

## 폼

- **light**: 보디슈트 위 한 겹의 주 장갑. 피부 노출량을 뜻하지 않는다.
- **heavy**: 몸 바깥에 두꺼운 단면과 깊은 단차를 가진 다층 장갑을 쌓는다.
  어깨·전완·하퇴의 보호 질량과 하중 지지 구조로 무게감을 만든다. 얇은 판을
  깃털처럼 겹치거나 무기를 추가하는 것으로 대체하지 않는다.
- **mobility**: 얇은 외향 패널, 뒤로 뻗는 핀·추진 구조와 빈 공간으로 방향성을 만든다.
  경장 장갑을 조금 줄이는 수준을 넘어 축소해서 봐도 다른 실루엣이어야 한다.
  관절의 움직임은 확보하되 노출 증가나 몸을 가늘게 만드는 것으로 대체하지 않는다.
- **overdrive**: 기준 장갑의 선택된 틈·패널 개방, 강해진 원본 속성 에너지,
  긴장된 손·버티는 자세를 함께 표현한다. 단순 정비·냉각 개방으로 끝내지 않는다.
  불꽃 계열은 기존 불꽃·열왜곡·불티, 전기 계열은 방전처럼 원본에 맞게 표현하며
  모든 원본에 불꽃을 강제하지 않는다. 얼굴과 장갑 구조를 효과로 가리지 않는다.
  모든 관절을 열거나 새 장갑·무기를 추가하지 않고, 부유도 기존 패널만 허용한다.

모든 폼에서 골격·흉곽·가슴·허리·골반·허벅지·종아리·키를 고정한다. 장갑 때문에
실루엣은 커질 수 있지만 맨살과 보디슈트 아래 몸 자체는 커지거나 가늘어지지 않는다.
다른 폼을 선택하면 기준 시트의 장갑 실루엣은 변형할 수 있다. 화풍의 설계 보존
지시는 이 명시적인 폼 전환을 막지 않는다. 경장 규칙과 노출 기본값은 유지한다.

게임의 폼 그림은 **액션** 출력으로 만든다(IMAGE_RULES 1·2절). 비교 초상은 정면 구도라
등 장비를 못 보여주고, 카메라를 풀어 보니 뒷모습이 나왔다. 그래서 액션 출력 프로필에
카드용 기본값을 둔다 — 방향·프레임을 따로 고르지 않으면 한 명·세로 전신·얼굴이 카메라를
향함·앞 가림 없음·폼 특징 장비가 보임. 명시적 방향·프레임 선택은 그 기본값을 이긴다.
액션 + 폭주에 둘째 첨부(그 폼 일반 그림)가 있으면 그 카메라·자세·크기를 유지하고
열린 상태만 바꾼다.

폭주 후속 초상은 전용 `overdrivePortrait` 연출을 사용한다. 일반 초상의 차분한 자세·
절제된 효과 대신 강한 긴장과 국소 에너지를 허용하되 2:3 전신·카메라·인물 크기는
유지한다. 명시적 표정과 선택 화풍은 존중한다. 절제된 화풍도 구조·긴장·에너지의
상대 차이는 보여야 한다. 최초 시트는 다중 뷰를 유지하고, 액션·일상에는 폭주 초상
전용 연출을 주입하지 않는다.

폭주 기준은 이미지 이어가기에서 **첨부 이미지의 장갑**이 기본이다.
중장은 기준 몸의 윤곽을 먼저 정하고 그 바깥에 장갑을 맞춘다. 특히 보디슈트로 덮인
허벅지를 장갑의 무게 때문에 굵게 만들지 않는다. 체형 보정은 외부 장갑의 질량 축소나
새 노출·커버리지 변경을 뜻하지 않는다. 몸과 외장 사이의 프레임·지지대 간격을 보인다.

중장 폭주는 `heavyOverdrive` 규칙을 추가한다. 기존 어깨·전완·허벅지 외측·정강이
패널이 있는 곳에서 큰 변위와 공기 틈이 보이도록 벌린다. 어깨는 구조가 허용하면
약 45~60도 개방하고 경첩·지지 연결·내부 방열부를 드러낸다. 새 패널을 만들지 않으며
가슴·골반 보호와 기존 피부·직물 경계, 카메라·인물 크기는 유지한다.
기준 폼이 `heavy`이면 적용하고, `reference`이면 첨부 장갑이 실제 중장인 경우에만
적용하도록 조건을 명시한다. 경장·고기동 폭주의 기존 규칙은 유지한다.

원하면 경장·중장·고기동을 명시한다. 최초 생성에는 첨부 장갑이 없으므로
경장을 기본으로 사용하고 다른 기본 폼을 고를 수 있다.

## 프롬프트와 자료의 자리

- `lib/prompt-spec.js`: 순수 자료. `PROJECT_RULES`, `FORM_PROFILES`,
  `OUTPUT_PROFILES`, `REFERENCE_SHEET_PROFILE`에서 앞으로 생성 규칙을 추가한다.
- `lib/prompt-anthro.js`: `buildPrompt(options)` 공통 조립기.
  기존 `buildAnthro`는 초상 호출 호환용이다.
- `lib/prompt-lifestyle.js`: 일상 카테고리·예시를 공통 조립기에 전달한다.
- `lib/prompt-ui.js`, `lib/prompt.css`: 세 모드 화면. 화면 문장은 `lib/words.js`.
- `prompt.html`: 공통 자원과 화면 모듈을 여는 껍데기.

첫 GENERATION INPUT 블록에서 텍스트만으로 새 인물을 만드는지, 첨부한 확정
이미지를 이어가는지 명시한다. ‘기준 시트’는 최초 생성의 **출력물**이며 기존 첨부를
뜻하지 않는다. 첨부 디자인 유지와 기준 이미지 대조 지시는 이어가기에만 들어간다.

새 인물의 GENERATION INPUT에는 생성 도구를 호출하는 어시스턴트용 안내도 포함한다.
참조 인수를 지원하는 도구라면 `referenced_image_paths`와
`num_last_images_to_include`를 모두 생략하고, 이전 대화의 이미지를 자동 선택하지
않도록 요청한다. 일반 복사 버튼으로 이 안내까지 함께 복사되므로 사용자가 별도
문구를 덧붙일 필요가 없다. 이는 받는 쪽에 전달하는 지시이며, 이 사이트가 외부
생성 도구의 호출 설정을 직접 바꾸는 것은 아니다. 이미지 이어가기에는 넣지 않는다.

출력 순서는 GENERATION INPUT → SOURCE IDENTITY → SOURCE ENGINEERING(장갑 모드만) →
CHARACTER IDENTITY → FORM DEFINITION/OVERRIDE(해당 모드만) → STYLE CORE → PROJECT STYLE EXTENSION →
MATERIAL SEPARATION → OUTPUT MODE →
CAMERA & PRESENTATION → CONSISTENCY / NEGATIVE LOCK → FINAL CHECK 이다.
최초 생성에 신체 치수를 지정하면 정체성 뒤에 치수 해석 문장이 붙는다.

### 확정 시트에서 액션을 만드는 짧은 경로

`reference + action`은 이미 확정된 시트가 설계 논쟁의 답을 가지고 있으므로 별도의
짧은 조립 경로를 사용한다. 인물 정체성, 핵심 장비, 선택 폼, 화풍, 재질, 장면 선택과
최종 검사만 싣는다. `PROJECT STYLE EXTENSION`, 초상 카메라, 공통 네거티브 잠금과
`MOUNT/OCCLUSION/CORRECTION/FAIL` 법조문은 이 경로에 넣지 않는다. 14개 화풍에는
액션 이어가기용 1~2문장 핵심 설명을 따로 두어 화풍 선택만으로 프롬프트가 다시
길어지지 않게 한다.

장착 교정은 모든 종에 공통으로 강제하지 않는다. 종 이름·선택 모티프·사용자 폼
조정에서 등 장비, 등껍질, 꼬리가 실제로 확인된 경우에만 짧은 긍정문 모듈을 붙인다.
등 장비는 몸 기준 장착점과 몸통을 함께 따르고, 등껍질은 척추 중앙, 꼬리는 후방 골반
중앙에서 시작한다고 서술한다. 자연스러운 가림은 허용한다. 다른 캐릭터에는 이 문구가
들어가지 않는다.

폼 설명도 액션 전용 요약을 사용한다. 기준 신체·핵심 장비는 유지하고 경장·중장·
고기동의 장갑 층과 실루엣 차이만 긍정문으로 기술한다. 폭주는 기존 패널의 개방과
에너지·긴장을 요약하고, 두 번째 일반 폼 이미지가 첨부되면 그 이미지의 카메라·자세·
인물 크기를 유지한다. 자유 입력 폼 조정은 요약 뒤에 그대로 보존한다.

이 짧은 경로의 순서는 GENERATION INPUT → SOURCE IDENTITY → CHARACTER IDENTITY →
SOURCE ENGINEERING → FORM DEFINITION → STYLE CORE → MATERIAL SEPARATION →
ACTION DIRECTION(선택값이 있을 때만) → OUTPUT MODE → FINAL CHECK 이다.

### 피부·보디슈트·장갑 재질 구분

모든 화풍과 생성 단계에 `MATERIAL SEPARATION`을 적용한다. 피부는 고유 피부색과
부드러운 해부학적 명암, 보디슈트는 봉제·장력 주름·유연한 직물 반응, 장갑은 두께·
단차·단단한 가장자리로 구분한다. 크림색이나 살색 슈트도 피부가 아닌 직물이며,
장갑의 유광 반사가 몸과 슈트 전체로 번지지 않게 한다.

이 규칙은 재질 구분이지 노출량 변경이 아니다. 슈트를 맨살로 바꾸거나 장갑을 더하지
않고, 참조의 기존 경계를 유지한다. 새 인물은 처음부터 재질 경계를 명확히 설계한다.
개방 폼도 기존 내부 재질을 드러낼 뿐 맨살을 기본으로 만들지 않는다.
선택 화풍을 유지하며 사진 같은 모공이나 직물 미세결을 모든 화풍에 강제하지 않는다.
일상컷에는 장갑·보디슈트 지시를 넣지 않고 피부와 의복 구분만 적용한다. 명시한 새틴·
가죽 등 고유 광택은 유지한다. 실제 이미지 품질은 생성 후 별도로 확인해야 한다.

화풍은 렌더링만 담당한다. 원본 성격·폼·카메라를 화풍이 강제로 바꾸지 않는다.
`glossy_promo`는 깔끔한 선화·성인 애니 얼굴·입체적인 2.5D 명암·고밀도 하드서피스
디테일을 결합한 프로모션 키아트다. 선명하면서 정돈된 색감과 선택적인 광택을 사용한다.
원근·배경·표정·얕은 심도·전투 효과를 화풍 자체에서 강제하지 않는다. 이 화풍은 체형·노출·장갑·카메라를 임의로
바꾸지 않으며 제목·번호·설명·UI·로고·워터마크를 그리지 않는다.
`mecha_cinematic_keyart`는 선명한 성인 애니풍 얼굴, 고채도 프로모 일러스트,
고밀도 하드서피스 메카 재질을 결합한다. 희뿌연 CGI 조명 대신 밝은 주광·색광,
강한 림라이트, 또렷한 중경, 다층 장갑과 내부 구조를 사용한다. 단독 컷은 캠페인
키아트의 밀도를 내고, 기준 시트와 비교 초상은 고정 배치·카메라·포즈를 유지한 채
동일한 얼굴·장갑·조명 품질을 적용한다. 기준 이미지의 얼굴·헤어·체형·장갑 덩어리·
노출 면적·장비·접합점은 바꾸지 않는다. 글자·번호·로고·의사 문자는 장갑과 배경에
만들지 않는다.
이 화풍의 얼굴은 사실적인 미인 얼굴에 눈빛만 더하는 방식이 아니다. 신규 인물의
기본 설계는 적당히 큰 눈·홍채, 간결한 코·입술, 부드러운 볼과 턱선의 성인 애니풍이다.
명시한 외형 설정과 확정된 인물의 특징·비례가 우선이며, 모든 종을 같은 귀여운 얼굴로
만들지 않는다. 얼굴 채색은 연속적인 부드러운 명암으로 입체감을 유지한다.
몸·머리카락·장갑·배경은 기존의 풍부한 볼륨과 반사·구조 밀도를 유지하고 전체를
셀 채색으로 단순화하지 않는다. 미소·입 벌림·정면 응시는 화풍에서 강제하지 않는다.
폼 초상·기준 시트·액션·일상컷에 같은 얼굴 표현을 적용한다. 이 변경은 복부 노출,
파이리의 색·헤어·장비 또는 샘플 이미지의 구도를 다른 캐릭터에 강제하지 않는다.
`bright_catalog`를 포함한 **14개 열쇠와 표시 이름을 유지**한다. 밝은 카탈로그
조명·재질을 보존하면서 고정 구도는 초상에만 적용한다.
`data/style.json`은 계속 `ART_STYLES`에서 생성한다.

원본 특징은 종에 맞는 핵심 몇 가지만 사용한다. 귀·꼬리·날개·뿔을 모두 강제하거나
원본 색을 피부색으로 직역하지 않는다. 친근함을 모든 캐릭터에 강제하지 않고
중장 폼의 무게감을 일괄 금지하지 않는다.
꼬리를 사용하는 디자인은 뿌리를 천골 또는 등허리 후면 중앙에 물리적으로 연결한다.
복부·앞허리·옆허리·가슴·앞 골반에서 시작하지 않으며, 기준 시트의 후면과 장비
확대컷에서 접합부와 몸에 가려지는 앞뒤 관계를 확인할 수 있어야 한다.

## 설정과 이미지

브라우저 설정은 `pkm_prompt_v2`에 카드별로 보관한다. 기존 `atelier_toolkit_v1`
값은 삭제하거나 자동으로 새 인물 정체성에 주입하지 않는다.
설정 내보내기와 별도의 콜라주 모드는 두지 않는다. 최초 기준 시트는 기존
폼 초상의 새 인물 만들기에만 적용되며, 새로운 모드나 저장 키를 만들지 않는다.
화면에 보이는 등록 이미지는 기준으로 자동 지정되지 않는다.

### 일상 갈래·설명·카메라

일상컷은 기존 인물의 정체성을 유지하면서 장면·의상·포즈를 바꾼다.
파트너 돌봄·교감, 여행·필드 탐험, 요리·나무열매, 축제·콘테스트 나들이,
취미·느긋한 휴식의 다섯 갈래에 장면 예시를 여섯 개씩 제공한다.
직업컷의 기본·섹시 예시는 포켓몬 돌봄·연구·보호·공예·여행·대회 지원으로
교체했다. 직업 예시의 내부 키는 저장 호환용으로 유지하며 화면 이름과 생성
지시문은 새 역할을 사용한다. 기존 트레이너나 센터 인물의 외모를 복제하지 않는다.

갈래·장면 설명은 `CAT_KO`·`EX_NOTE`에서 읽는다. 포즈·프레이밍·화각의
`*_GUIDES`는 한국어 설명과 영어 생성 지시를 함께 관리한다. 각 장면 입력 아래에
설명을 표시하고 `aria-describedby`로 연결한다. 직접 입력·자동 선택에도 설명이 있다.

포즈는 자동 외 36종이다. 프레이밍은 환경 와이드·전신·무릎 위·허리 위·가슴 위·
얼굴·손/소품 디테일의 7종, 화각은 24·35·50·85·135mm 느낌의 5종을 제공한다.
프레이밍은 화면에 담는 범위, 화각은 원근감, 화면 비율은 캔버스 형태를 뜻한다.
렌즈 수치는 그림을 설명하는 단서이며 실사 표현이나 배경 흐림을 강제하지 않는다.
명시한 포즈·방향·카메라 선택은 예시의 부수적인 구도보다 우선한다.

카메라 메뉴는 액션·일상컷에서 사용하며 기준 시트·비교 초상의 고정 구도에는
들어가지 않는다. `scenes[mode].frame`·`lens`는 카드·모드별로 저장하고, 기존
`camera` 자유 입력값은 추가 지시로 보존한다. 예전 저장값에는 새 메뉴를 자동으로 채운다.

### 액션 연출 선택

액션 탭에는 준비·대치, 근접 공방, 원거리 기술, 회피·지상 기동, 도약·공중 기동,
방어·호위, 구조·돌파, 훈련·시연, 전투 직후의 9개 갈래와 각 3개의 예시가 있다.
갈래를 바꾸면 이전 예시만 초기화한다. 예시를 고르지 않으면 선택한 갈래에 맞춰
구성하며, 갈래도 자동이면 기존 장소·상황과 추가 지시를 사용한다.

동작 타이밍, 무장·장비 사용, 기술·에너지 발현, 효과량, 속도감, 전장·장소의
6개 메뉴로 연출을 조절한다. 각 항목에는 자동 선택과 한국어 설명이 있다.
포즈 목록은 액션 전용 16종을 사용하며, 과거에 저장한 공통 포즈가 선택되어
있으면 해당 항목도 표시해 유지한다. 프레이밍·화각·자유 입력은 그대로 함께 쓴다.

자료는 `ACTION_CATEGORIES`, `ACTION_CONTROLS`, `ACTION_POSES`가 관리한다.
선택값은 `scenes.action.action`에 카드별로 저장하며, 없는 값과 유효하지 않은
저장값은 자동으로 처리한다. 조립기는 선택된 항목만 `[ACTION DIRECTION]`에
추가한다. 모든 값이 자동이면 이 블록은 생기지 않는다.

명시한 세부 연출은 예시의 부수적인 제안보다 우선한다. 효과량 없음은 추가 VFX를
억제하고, 기술 발현 없음은 새 속성 에너지를 억제한다. 기존 센서 등은 유지한다.
장비가 없는 경우 동작을 조정하며 새 무장·날개·꼬리·추진기를 임의로 붙이지 않는다.
강한 기술을 골라도 체형·장갑 두께·커버리지·개방 상태나 폼은 바뀌지 않는다.
기준 시트·폼 초상·일상컷에는 액션 연출 블록이 들어가지 않는다.

### 장면 랜덤과 잠금

액션·일상컷의 장면 선택 항목에는 개별 랜덤과 잠금 버튼이 있다. 전체 랜덤은 현재
모드에서 잠기지 않은 항목만 변경한다. 갈래, 예시, 표정, 포즈, 방향, 프레이밍,
화각, 화면 비율과 모드별 세부 선택을 대상으로 하며, 직접 입력 문구와 인물·화풍·폼은
유지한다. 자동·직접 입력은 추첨 대상에서 제외하고, 다른 후보가 있으면 현재 값과
다른 값을 고른다. 예시를 잠그면 종속된 갈래도 랜덤 변경에서 보호한다.

잠금은 랜덤 변경만 막으며 직접 선택을 막지 않는다. 잠금 상태는 카드·모드별
`scenes[mode].randomLocks`에 저장된다. 장면 랜덤 로직은 `lib/prompt-random.js`에
있고, `prompt-random.cjs`와 `prompt-random-dom.cjs`가 개별/전체 랜덤, 종속 관계,
잠금, 직접 입력 유지, 카드·모드 분리, 저장 복원을 검사한다. 저장은 화면 상태가
반영되는 시점에 처리해 빠른 카드 전환에도 최신 선택과 잠금이 보존되도록 한다.

### 외형을 이미지와 색상으로 선택

새 인물 만들기의 체형·헤어스타일에는 PNG 선택 목록이 있다. 기존 여성 체형
17개와 여성 헤어 33개를 `atelier/assets/figures`의 공개 PNG로 다시 연결했다.
원본 그림을 이 저장소에 복제하지 않고 `lib/figures.js`의 `pngURL`에서 주소를
관리한다. PNG가 없는 항목이나 이미지 로드 실패는 기존 Canvas 도식으로 표시한다.
선택 카드의 그림 영역과 두 줄 이름 영역은 높이를 고정해 서로 정렬된다.

눈동자 색·왼쪽 눈 색·머리색 팔레트는 `COLOR_KEYS`와 `COLOR_HEX`를 사용한다.
그림·팔레트·셀렉트박스는 같은 파라미터를 바꾸며, 잠금과 직접 입력 및 카드별
저장도 그대로 적용된다. 이미지 이어가기에서는 외형 선택기를 숨기고 기준 이미지의
정체성을 유지한다. 설정 내보내기나 성별 선택을 다시 추가하지는 않았다.

이미지 파일명·스타일 키·`byForm` 구조는 그대로다.
여성 폼 초상과 폼별 action, 폼 밖 casual을 해당 화풍에서 읽는다.
카드와 그룹 원본은 계속 `tools/fetch-cards.py`에서 생성한다.


엔진 검사는 14개 화풍 × 3개 모드 × 4개 폼, 기준 정체성 우선순위,
폭주 기준, 생성 단계 치수·이색 눈, 모드별 입력 제외를 확인한다.
모든 화풍·폼에서 최초 기준 시트의 필수 구성을 확인하고, 이미지 이어가기·액션·
일상컷으로 그 구성이 새어 들어가지 않는지도 검사한다.
화면 검사는 모드 전환·잠금 무작위·기준 이미지 전환·복사 실패 대안·
카드별 설정 복원·세 화면 크기의 스크롤을 확인한다.
이 검사는 프롬프트와 화면 동작 검증이며 실제 생성 이미지의 품질 판정은 아니다.

`prompt-casual`은 모든 선택지의 설명과 생성 문구 연결, 직업 교체, 카메라의 모드
분리를 확인한다. `prompt-casual-dom`은 jsdom·실제 Preact 화면에서 설명 갱신,
직접 입력, 이전 저장값 호환, 캐릭터/모드 전환과 저장 복원을 확인한다. 이 DOM
검사는 실제 브라우저의 배치·스크롤·시각 검사를 대신하지 않는다.

`prompt-action`은 갈래·예시·세부 선택·포즈가 생성 문구에 연결되는지, 선택값이
없거나 잘못됐을 때 추가 지시를 만들지 않는지, 폼과 다른 모드에 영향을 주지 않는지
검사한다. `prompt-action-dom`은 실제 Preact 메뉴와 설명 갱신, 종속 예시 초기화,
기존 포즈·카메라 값 호환, 카드/모드 분리와 저장 복원을 검사한다.

`prompt-controls`는 PNG 로드·그림/색상 선택·잠금·직접 입력·저장 복원과
기준 이미지 모드의 외형 제외, PNG 실패 시 Canvas 대체를 확인한다.
오프라인 브라우저 검사에서는 원본 PNG를 `img/figure-previews/`에 같은 이름으로
두면 공용 하네스가 해당 파일을 사용한다. 이 폴더는 검사 전용이며 Git에 올리지 않는다.

### 중장 보호 범위와 큰 장갑판

중장은 경장의 판에 겹판만 더하지 않고 두께와 보호 면적을 함께 늘린다. 상부 흉부·옆갈비·등을
연결하는 외장과 허벅지 앞·바깥쪽을 덮는 독립 장갑을 기본으로 한다. 하퇴는 넓은 전면 주 장갑판과
깊은 측면 하우징으로 정리하고 뾰족한 겹판 반복을 피한다. 흉갑은 종별 구조에 맞춰 일체형 또는
분절형으로 설계한다. 신규 디자인의 복부는 직물 또는 가동 장갑을 선택할 수 있으며, 이어가기에서도 중장은 기존 복부 위에 가동 외장을 덮는다. 명시적 커버리지 요청이 우선한다. 원본 종의 색이나 장비를 다른 종에 강제하지 않는다.

보호 범위 확대는 기존 슈트 위 외장 변환만 허용한다. 내부 피부·직물 경계와 기준 체형,
머리–골반·골반–무릎·무릎–발목 비율을 유지하며 장갑에 맞춰 몸을 늘리거나 부풀리지 않는다.
중장 폭주는 같은 큰 판을 지지대와 경첩으로 벌려 공기 틈을 드러낸다. 넓은 하퇴 장갑은
큰 문처럼 열고 잘게 쪼개거나 새 핀을 더하지 않는다. 가슴·골반 보호는 유지한다.

### 기준 시트 체형 우선순위와 장갑 내부 공간

이미지 이어가기에서는 기준 시트의 주 정면 전신을 신체 비율의 우선 기준으로 삼는다.
후면·확대컷은 장비·접합부·국소 세부를 참고하며 서로 다른 체형을 평균내지 않는다.
같은 표면의 피부·직물 표현이 충돌하면 정면을 우선하되, 뒤에서만 보이는 면의
별도 의복 설계까지 오류로 간주하지 않는다. 명시적으로 확정한 다른 체형 기준은 우선한다.

중장은 기존 인물의 외장 교체로 해석한다. 골반·고관절·안쪽 허벅지·흉곽 위치와 폭을
유지하며, 장갑 내부를 몸으로 채울 필요가 없다. 지지대와 빈 공간을 허용하고 외측·전방으로
외장 두께를 확보한다. 큰 흉부 장갑이 가슴이나 흉곽 확대를 뜻하지 않는다.
추가 장갑 참고 이미지에 체형 변화가 있어도 그 체형을 상속하지 않는다.
재질 규칙은 명시적인 폼의 외장 보호 범위 확대를 막지 않지만 내부 피부·직물 경계는 유지한다.
이 규칙은 생성 지시이며 실제 이미지의 체형 보존을 보장하는 검사는 아니다.

### 원본 특징을 기능성 기계 구조로 번역

장갑 생성은 원본의 대표 특징 → 성인 인물 → 폼 → 화풍 → 출력 구도 순서로 설계한다.
공통 SOURCE ENGINEERING은 모든 화풍에 적용하고 일상컷에는 넣지 않는다.
신규 생성은 이전 인물이나 장갑 템플릿을 재활용하지 않고, 대표 특징 몇 가지를 기능·장착점·관절이
읽히는 장비로 만든다. 가장 강한 특징은 작은 장식이 아니라 주요 실루엣이 된다.
이상해씨처럼 등 구근이 있는 원본에는 둥글고 겹층인 씨앗 리액터, 식물 특징에는 잎형 핀과
마디형 덩굴 케이블·포드 단말을 사용할 수 있다. 이 예시는 해당 특징이 있는 종에만 적용한다.
다른 종은 고유 특징으로 설계하며 초록색·붉은 눈·식물 장비를 공통 강제하지 않는다.

시각적 무게는 원본의 핵심 외부 장비·어깨 구조·하퇴 장갑에 배분한다. 인체 치수를 장비에 맞춰
키우지 않는다. 승인된 이미지로 이어갈 때는 새 디자인 지시 대신 기존 핵심 장비·색·무늬·장착 구조를
유지하고 선택 폼의 외장 변환만 허용한다. 폭주는 기존 장비를 개방한다.
화풍이나 원본 설계 문장이 기준 시트·단일 초상·액션의 출력 구도를 바꾸지는 않는다.

### 경장 구조 깊이와 글로시 프로모 명암 보완

경장은 보호 장갑 한 겹과 소형 지지 프레임으로 정의한다. 얇은 장식판을 뜻하지 않으며,
기존 판의 단면·모서리·연결 홈·가동 관절을 읽을 수 있게 한다. 중장의 다층 외장과 구분한다.
신규 디자인에 연속 보디슈트를 필수로 요구하지 않는다. 직물은 필요한 연결 부위에 사용할 수 있고,
넓은 밝은 슈트 면이 디자인을 지배하지 않도록 한다. 명시적으로 요청한 슈트는 허용하며,
기준 이미지의 커버리지·피부/직물 경계는 유지한다. 노출 증가나 중장화로 대체하지 않는다.

글로시 프로모는 얼굴의 선과 덩어리 명암을 명료하게 하고 피부·입술 광택을 절제한다.
장갑에는 면의 밝기 차이·모서리 반사·깊은 연결 틈으로 입체감을 준다. 이는 기존 구조의 표현이며
새 장비나 체형 확대를 허용하지 않는다. 등 구근을 가진 원본의 리액터는 겹친 단단한 외피,
기계 받침과 케이블 소켓으로 구체화한다. 기준 시트 구성과 카메라는 유지한다.

### 기준 시트 프롬프트 중복 정리

기준 시트 우선 흐름과 정면·후면 전신·상세 4칸, 3:4 세로 구성은 유지한다.
신규 입력 안내, 원본 설계, 재질 구분, 경장, 글로시 화풍과 시트 설명의 중복을 줄였다.
출력 블록은 뷰/상세 구성, 카메라는 배치/화각, 일관성 블록은 뷰 사이 일치를 담당한다.
시트의 최종 점검은 전용 문장만 출력한다. 신규 생성은 체형을 먼저 정하고 장갑을 맞추며,
이미지 이어가기에서만 기준 이미지의 체형 고정과 외장 변환 규칙을 출력한다.
외형 선택값 및 우선순위, 중장 체형 분리, 폭주 개방 규칙은 유지한다.

외형 선택값이 없는 이상해씨·경장·glossy_promo·신규 기준 시트 비교에서
전체 출력은 16,151자에서 6,629자로 약 59% 줄었다. 이는 텍스트 길이 측정이며
생성 이미지의 품질 개선을 검증한 수치는 아니다.

### 좌우 장갑 구조 대칭

장갑 모드에만 대칭 규칙을 한 번 출력한다. 어깨·팔·허벅지·무릎·정강이·신발의
좌우 부품 구성·치수·해부학적 부착 높이를 맞춘다. 명시적으로 요청하거나 승인한
비대칭 장비만 예외로 인정하며, 기준 이미지의 우연한 오류를 의도된 비대칭으로 취급하지 않는다.
포즈·원근·케이블 곡선·폭주 판 개방 각도는 달라도 같은 부품 구조를 유지한다.
후면과 상세는 정면에서 정한 부품을 보여 준다. 일상 의상에는 이 규칙을 적용하지 않는다.

### 글로시 프로모 얼굴 표현 강도

기존의 부드러운 얼굴 명암 문장을 교체했다. 선명한 눈 윤곽·윗속눈썹·홍채,
분명한 입 표현·명암 경계·선택적인 하이라이트·덩어리로 구분한 머리카락으로
얼굴도 장갑과 같은 프로모션 렌더링 강도를 갖게 한다. 선택한 눈매·얼굴형·성인 나이·표정은
유지하며, 각진 느낌은 얼굴 구조 변경이 아닌 명암으로 표현한다. 장갑과 맞추는 것은
선명도와 대비이며 피부에 금속 광택을 적용하지 않는다. 다른 화풍은 변경하지 않는다.

### 나이 설정과 렌더링 문구 분리

나이 선택 항목과 저장값은 유지한다. 공통 인물·폼·출력·점검 문구와 글로시 프로모의
반복 adult 수식어를 제거하고, 선택한 나이 또는 승인된 인물의 나이를 따른다.
귀여움 보조 문구도 나이·얼굴형 유지로 줄였다. youthful adult 선택값은 그대로 두고
그 해석은 20대 인물로 유지한다. 다른 화풍의 고유 얼굴 렌더링 문장은 변경하지 않는다.

### 장갑 폼: 부위별 경장 / 전신 중장

경장은 어깨·팔·골반/허벅지·하퇴의 독립된 부위별 장갑과 유연한 연결부로 구분한다.
판 두께와 기계 디테일은 충분히 유지하며, 경장을 피부 노출량으로 정의하지 않는다.
중장은 흉부·등·옆구리·복부·허리·골반·팔·허벅지·무릎·하퇴·발의 앞/옆/뒤를
감싸는 전신 외장이다. 복부·허리·골반은 가동 분절판, 관절에는 작은 유연 공간을 둔다.
얼굴은 보이며 헬멧은 필수가 아니다. 중장 선택 자체가 기존 피부/직물 위 외장을 허용하고,
기존 노출 범위를 보존하려고 넓은 창을 남기지 않는다. 명시적 커버리지 예외는 우선한다.
신규/기준 이미지 이어가기 모두 적용하며 내부 체형과 원래 피부/직물 구분은 유지한다.
고기동은 방향성 핀·추진 구조·관절 여유로 구분한다. 중장 폭주는 전신 외장 부품을 보존한 채
개방하며 경장처럼 판을 없애지 않는다. 이 규칙이 앞 절의 복부 커버리지 유지 설명보다 우선한다.

### 등갑·꼬리의 신체 기준 장착점과 가림

`PROJECT_RULES.sourceMounts`를 장갑 모드의 SOURCE ENGINEERING에 한 번 연결한다.
등갑은 척추 중심의 등 받침에 장착하고 몸통 회전을 따른다. 꼬리는 등갑과 분리된
골반 후면 중앙의 천골 장착점에서 뒤로 뻗은 뒤 굽히며, 말린 끝부분이 옆으로
보이더라도 뿌리를 옆구리나 팔로 옮기지 않는다. 등갑 받침·꼬리 뿌리·추진 노즐은
별도 구조다. 있는 장비에만 적용하며 새 등갑·꼬리·추진기를 강제하지 않는다.

정면에서 몸통과 팔에 가려지는 것은 정상이다. 전신·장비를 프레임 안에 담으라는
지시는 모든 부품을 노출하라는 뜻이 아니다. 보여주려고 장비를 옆으로 옮기거나
카메라 쪽으로 돌리지 않으며, 카메라·여백·체형도 변경하지 않는다.
경장·중장·고기동·폭주의 외장 변환과 패널 가동은 허용하되 주요 장착점은 유지한다.

기준 시트의 후면과 기존 장비 확대칸으로 접합 관계를 보여 주고, 이어가기에서는
그 관계를 신체 좌표로 해석한다. 후면 이미지상의 좌표를 정면에 그대로 복사하지 않는다.
명시한 대체 장착 설계는 우선한다. 신규·이어가기의 초상·액션에 적용하고 일상컷에는
추가하지 않는다. 자동 검사는 프롬프트 연결과 모드 분리만 확인하며 실제 생성물의
위치 보존을 보장하지 않는다.


### 기준 이미지 보존과 장착 교정의 우선순위

첫 장착점 패치 후에도 꼬부기의 말린 꼬리가 팔 옆 원판처럼 보이는 결과가 보고됐다.
기존 `sourceDesignReference`의 장착 구조 보존과 `sourceMounts`의 승인 이미지 예외가
교정 지시와 충돌할 수 있어, 이어가기에는 MOUNT CORRECTION PRIORITY를 명시한다.
같은 폼을 이어가도 장착 오류를 교정하며, 이 제한적인 교정은 기준 이미지·폼·화풍의
장비 보존 지시보다 우선한다. 인물·체형·포즈·부품 구성·표면 디자인은 유지한다.
이미지 승인이나 가려진 접합부만으로 옆구리 장착을 승인한 것으로 해석하지 않는다.
대체 장착점은 사용자가 명시적으로 지시할 때만 허용한다. 말린 꼬리 면은 실제 3차원
방향을 따르며 카메라를 향하는 원판처럼 회전시키지 않는다.

회귀 검사는 신규/이어가기, 초상/액션/일상, 모든 장갑 폼의 적용 범위와 프롬프트 길이를
확인한다. 보고된 이미지 문제의 실제 원인을 확정하거나 재생성 품질을 보증하는 검사는 아니다.


### 전면 가독성보다 자연스러운 후면 장비 가림 우선

신규·이어가기 모두 장착점 → 자연스러운 가림 → 전면 가독성 순으로 적용한다.
`Allocate visual mass`와 기준 시트의 장비 전체 가시성 요구를 제거한다.
올바른 기하에서 꼬리가 완전히 가려지면 그대로 숨기고 등갑도 자연스럽게 보이는
부분만 표현한다. 전면 가독성은 얼굴·인체 실루엣·장갑·색상·전면 부품으로 확보한다.
신규 시트와 이어가기 초상의 CAMERA & PRESENTATION에도 같은 우선순위를 명시한다.

실패 조건은 측면에 직접 장착한 꼬리, 전시용으로 돌린 소용돌이 원판, 보여주려고
측면으로 옮긴 등갑, 후면 장비 노출을 위한 프레이밍·여백·포즈·체형 변경이다.
정상적인 꼬리 끝이 투영상 팔 옆에 겹쳐 보이는 것 자체는 실패가 아니다.
기존 후면 뷰와 장비 확대칸에서 접합부를 확인하며 일상컷에는 장갑 규칙을 추가하지 않는다.
프롬프트 연결·적용 범위·길이는 자동 검사하되 실제 이미지 개선은 별도 확인이 필요하다.


### 비교컷의 일관된 전면 3/4와 특징 보존

기준 시트 이후 초상 비교컷은 몸통·골반·장착 장비가 함께 정면에서 25~35도 돌아가는
전면 3/4를 기본으로 한다. 얼굴은 자연스럽게 카메라로 향하고, 경장·중장·고기동·폭주에
동일한 회전 방향과 각도를 유지한다. 기존 정면 비교컷에서도 이 각도를 처음 설정할 때는
카메라 높이·초점거리·인물 크기·프레이밍·배경을 유지한다. 명시한 사용자 시점은 우선한다.
기준 시트의 정면은 체형 기준이며 초상 포즈를 정면으로 고정하지 않는다.
신규 기준 시트의 정면/후면 배치와 액션·일상의 자유 화각은 그대로 유지한다.

앞 절의 완전 은폐를 강하게 요구하는 문구는 이번 규칙으로 대체한다. 등갑 폭과 테두리,
뒤로 연결된 꼬리 끝의 자연스러운 측면 돌출은 허용한다. 위치 오류를 해결하려고 장비를
삭제·축소·강제 은폐하지 않으며, 자연스러운 가림도 허용한다. 장비만 따로 측면으로 옮기거나
카메라를 향해 돌리는 것은 금지하고 몸 전체와 함께 회전하는 것은 허용한다.

자동 검사는 모든 장갑 폼의 이어가기 초상에만 기본 각도가 들어가는지, 특징 보존 규칙과
프롬프트 길이가 유지되는지 확인한다. 실제 이미지 생성 성공률을 검증한 변경은 아니다.


### 신규 설계 명세와 인셋 일치

신규 장갑 생성의 SOURCE ENGINEERING을 창의적 사전 설계 지시로 교체한다. 수신
어시스턴트가 사용자 선택 → 종별 선택 순으로 핵심 장비를 정하고, 종의 생물학적 특징과
타입을 결합한 대표 기능 장비 하나 및 선택적 표면 디테일 하나를 짧게 명세한다.
이 명세를 같은 이미지 호출에 넣고 결과와 함께 남기도록 요청한다. 별도 이미지 호출이나
추가 UI는 없다. 정적 생성기가 수신 어시스턴트의 최종 설계를 자동 수집·저장하는 기능은
아니므로, 후속 생성에는 승인 이미지와 필요한 설계 기록을 함께 제공한다.

장비 존재와 가시성/수납은 별개다. optional은 자동 부재가 아니며, 가려지거나 수납된
부품도 제거된 것으로 해석하지 않는다. 이어가기에서 확인할 수 없는 부품은 미확정으로
두며 승인된 후면 뷰·기록으로 확인한다. 핵심 장비의 기능·정체성은 보존하지만 중장의
보호판, 고기동 핀 및 가동 구조 등 선택 폼의 외장 변화는 허용한다. 폭주는 기존 장비를
개방한다. 일상컷에는 이 장갑 보존/사전 설계 규칙을 삽입하지 않는다.

기준 시트 인셋은 본체에 설치한 동일 부품의 확대다. 패널·색·문양·수로·체결부·장착점을
맞추며, 확대에 따른 세부 묘사는 허용하되 독립적인 구조 재설계는 금지한다. 좋은 디테일은
명세 단계에서 먼저 정하고 본체와 인셋에 함께 적용한다. 기존 장착점 및 25~35도 비교컷
규칙은 유지한다. 씨앗 반응기 같은 고정 예시는 공통 지시에서 제거한다.

회귀 검사는 세 종 × 인물 모드 × 출력 모드 × 장갑 폼의 적용 범위, 고정 종 예시 제거,
장비 상태 구분과 명세 기록 지시를 확인한다. 인셋 시각 일치와 창작 품질은 별도 이미지
검증 대상이며 텍스트 검사 통과로 보장하지 않는다.


### 공간 배경 기본값과 비교컷 연속성

기준 시트에는 실험실·격납고·온실 등 디자인에 어울리는 공간과 깊이를 기본으로
요청한다. 인물·장비가 읽히도록 배경 대비와 디테일을 절제하고, 시트 전체 조명을
일치시킨다. 수묵·회화 화풍은 간결한 공간 암시로 표현할 수 있다. 배경 때문에
인물을 줄이거나 여백을 늘리지 않는다. 사용자가 지정한 배경은 기본값보다 우선한다.

후속 비교컷은 같은 장소·배경 배치·조명을 폼 전체에서 유지한다. 참조가 빈 배경이면
장소를 한 번 정한 뒤 이어간다. 액션·일상컷은 기존의 장면별 환경 선택을 유지하며
비교컷의 장소 고정을 상속하지 않는다. 이 지시는 텍스트 기본값이며 생성 결과를
자동 보정하거나 배경 일관성을 보장하는 기능은 아니다.


### 외형·장면 선택 문구 구체화 (2026-09-19)

현재 화면의 외형 선택 273개를 점검했다. 색·계통처럼 이미 명확한 선택값은
유지하고, 205개 외형 선택에 `PARAM_GUIDES`의 한국어 설명과 영어 구조 설명을
연결한다. 모든 외형 메뉴 아래에 적용 범위와 자동/직접 입력 안내를 표시한다.
기존 저장 열쇠·값과 잠금을 변경하지 않고 생성 시에만 설명을 조립한다.

- 둥근 턱은 하관 폭을 유지하는 넓은 U자 턱끝이다. V자 끝이나 볼살 추가로
  대체하지 않는다. 다른 턱 선택에는 이 조건을 넣지 않는다.
- 체형은 장갑 아래 신체이며, 보통·균형은 선택한 체형 안의 중간값이다.
  흉곽과 가슴, 골반 폭과 다리 굵기, 다리 길이와 근육을 구분한다.
- 얼굴의 국소 윤곽·폭·길이·눈 크기·각도가 인상이나 넓은 얼굴형을 세분한다.
  눈매에 포함된 기본 각도는 별도 눈꼬리 선택이 있을 때 중복 출력하지 않는다.
- 헤어는 컷의 구조·고유 길이를 유지한다. 픽시·버즈·크루·보브·한쪽을 민 긴 머리는
  일반 길이 선택을 해당 컷 범위로 해석한다. 원래 저장값은 유지하고 화면에 안내한다.
  직접 입력은 그대로 전달한다. 머릿결은 한 올 굵기, 볼륨은 머리 덩어리 부피다.
- 왼쪽 눈 색을 비우면 양쪽에 기본 색을 적용한다. 오드아이는 인물 본인의 좌우를
  지정하며, 같은 색을 두 번 선택하면 중복 항목을 생략한다.
- 방향 22개와 일상 세부 선택 16개에 구체적인 설명을 연결한다. 아래 보기(시선)와
  하이앵글(카메라)을 구분하고, 단일 일상컷의 balanced 동작량을 컷 수 비율로 쓰지 않는다.
- 공통 정체성·재질·대칭·경장·기준 시트·프로모 키아트 설명의 반복을 줄였다.
  공간 배경, 장비 존재/가림 구분, 후면 장착, 인셋 일치, 폼 변경 권한은 유지한다.

검증 입력은 `tests/fixtures/appearance-bulbasaur.json`에 보관한다. `glossy_promo`,
경장, 새 기준 시트, smirk에서 동일 설정 출력은 12,350자에서 11,792자로 줄었다.
빈 외형의 기존 10,000자 제한도 유지하며 상세 설정에는 별도 12,000자 검사를 둔다.
개별 선택에 따라 출력 길이는 달라지므로 모든 조합의 길이를 보장하는 값은 아니다.

`prompt-appearance.cjs`는 외형 273개와 화풍·출력·폼 336개 조합, 둥근 턱의 범위,
헤어/눈 충돌, 직접 입력과 참조 모드 분리를 검사한다. 이전 조립기로 되돌린 변이에서
둥근 턱 검사가 실패하는 것도 확인했다. `prompt-appearance-dom.cjs`는 jsdom에서
실제 Preact 생성기를 띄워 자동을 포함한 메뉴 305회 선택, 설명과 출력 갱신,
모드 전환, 저장 복원 후 동일 출력을 확인한다. 이미지 자체를 생성한 검사는 아니다.

```bash
node tests/prompt-appearance.cjs
NODE_PATH=<jsdom·preact가 있는 node_modules> node tests/prompt-appearance-dom.cjs
```
